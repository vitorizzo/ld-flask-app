Procedura aggiornata per aprire una nuova chat (v2)
1) Messaggio 1 — Regole operative
   Incolla new_chat.md (integrale)

   2) Messaggio 2 — Mappa progetto
   Incolla project_map.md (integrale)
   (così hai subito: struttura + base raw + convenzioni + riferimenti)

3) Messaggio 3 — Stato progetto
   Incolla status.md (integrale)

4) Messaggio 4 — Obiettivo della sessione

Formato consigliato:
    Obiettivo di questa chat: (1 frase)
    Cosa è già pronto: (bullet)
    Cosa manca: (bullet)
    Vincoli: (es. “non toccare legacy”, “logger obbligatorio”, “step-by-step”)
    File di partenza da leggere: (1–3 link raw)

Esempio per adesso:
    Obiettivo: “Creare UI Automations V2 ex-novo”
    Vincoli: “non toccare UI legacy Trello; step-by-step; log chiaro”
    File da leggere: templates/automations_v2.html, routes/automations_v2.py, eventuale nuovo static/js/automations_v2.js

Regola pratica che evita blocchi e perdite di contesto
Dopo ogni obiettivo chiuso o milestone (es. “UI base pronta / CRUD ok / deploy ok”) scrivi: “aggiorna situazione” e 
io rigenero status.md (e project_map.md se serve).
